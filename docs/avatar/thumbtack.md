# Thumbtack

Thumbtack is the character that ships with VirtualTour. Its default look is a red push pin with a short flared top, narrow cylindrical waist, wide domed base and thin metal needle. The original round-top look is also available as a variant. Both were made for this project. The push pin is the default for `withAvatar(thumbtackPack())` and the working example for [making your own pack](./make-a-pack).

## The pack

| | |
|---|---|
| Frame size | 96 by 96 CSS pixels |
| Sheet | `sheet.png`, 10 columns, drawn at twice the CSS size (`scale: 2`) |
| Dock hint | `end`, with an 8 pixel gap |
| License | CC0 1.0, no credit required |

Animations: `rest`, `blink`, `wobble`, `look-around`, `wave`, `point-left`, `point-right`, `point-up`, `point-down`, `think`, `cheer`, `pop-out` and `boing`.

| Role | Animation |
|---|---|
| `rest` | `rest` |
| `idle` | `blink`, `wobble`, `look-around` |
| `greet` | `wave` |
| `point` | `point-left`, `point-right`, `point-up`, `point-down` |
| `think` | `think` |
| `celebrate` | `cheer` |
| `exit` | `pop-out` |
| `alert` | `boing` |

The pack has no `point.any`, so a step with a target always points in one of the four directions.

## Files

The package exports `virtual-site-tour/thumbtack/pack.json` and `virtual-site-tour/thumbtack/sheet.png` for the default push pin, plus `virtual-site-tour/thumbtack/round/pack.json` and `virtual-site-tour/thumbtack/round/sheet.png` for the round-top variant. `thumbtackPack(baseUrl, { variant })` loads either pack. `baseUrl` is the directory that holds `thumbtack/` when you host the files yourself.

The frames are generated by code, not drawn by hand. From the repository root, run `node packages/core/tools/build-thumbtack-pack.mjs` to regenerate both variants, or add `pushpin` or `round` to regenerate only one. The art is dedicated to the public domain; see [Licensing](../licensing).
