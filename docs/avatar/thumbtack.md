# Thumbtack

Thumbtack is the character that ships with VirtualTour: a red push pin with a round head, drawn for this project. It is the default for `withAvatar(thumbtackPack())` and the working example for [making your own pack](./make-a-pack).

## The pack

| | |
|---|---|
| Frame size | 96 by 96 CSS pixels |
| Sheet | `sheet.png`, 10 columns, drawn at twice the CSS size (`scale: 2`) |
| Dock hint | `end`, with an 8 pixel gap |
| License | CC0 1.0, no credit required |

Animations: `rest`, `blink`, `wobble`, `look-around`, `wave`, `point-left`, `point-right`, `point-up`, `point-down`, `think`, `cheer`, `pop-out` and `boing`.

| Role | Animation |
|---|---|
| `rest` | `rest` |
| `idle` | `blink`, `wobble`, `look-around` |
| `greet` | `wave` |
| `point` | `point-left`, `point-right`, `point-up`, `point-down` |
| `think` | `think` |
| `celebrate` | `cheer` |
| `exit` | `pop-out` |
| `alert` | `boing` |

The pack has no `point.any`, so a step with a target always points in one of the four directions.

## Files

The package exports `virtualtour/thumbtack/pack.json` and `virtualtour/thumbtack/sheet.png`. `thumbtackPack(baseUrl)` loads them from a directory you choose when you host them yourself.

The frames are generated by code, not drawn by hand. `tools/build-thumbtack-pack.mjs` in the repository describes each pose as a few parameters and writes the SVG frames, the sheet and `pack.json`. The art is dedicated to the public domain; see [Licensing](../licensing).
