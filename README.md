# VirtualTour

VirtualTour is an open-source guided-tour and onboarding library (MIT), a fork of [driver.js](https://github.com/kamranahmedse/driver.js).

Documentation starts at [docs/guide/getting-started.md](docs/guide/getting-started.md).

Implementation is in progress. See [docs/plan/15-work-units.md](docs/plan/15-work-units.md) for the work units.

## Known limitations

Screen-reader behavior is verified with automated axe checks, but has not yet been manually tested with VoiceOver or other screen readers.
